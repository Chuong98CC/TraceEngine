# S2M2 Stereo Depth

Stereo metric depth on an image pair (ONNX or TensorRT). Computes depth for both views
(right view via a horizontal-flip trick) and can save depth `.npz`, a
side-by-side visualization, and a coloured point-cloud `.glb`.

```bash
python tools/infer_s2m2.py --frame_index 0 --save_depth --save_viz --save_glb
```

| Argument | Default | Description |
|---|---|---|
| `--trt_engine` | `weights/s2m2/S2M2_XL_640_480_v2_torch21_fp16.engine` | S2M2 TensorRT engine |
| `--frame_index` | `0` | Frame index to process |
| `--conf_thresh` / `--occ_thresh` | `0.5` | Confidence / occlusion thresholds (mark pixels invalid below) |
| `--output` | `output/s2m2` | Output directory |
| `--save_depth` / `--save_viz` / `--save_glb` | off | Toggle each output |
